# lunatic

게임 기획/리서치 문서를 Codex가 안정적으로 참고할 수 있도록 기본 템플릿을 제공합니다.

## Quick Start
1. `docs/game-design/GDD.md`에 게임 핵심 방향을 먼저 채웁니다.
2. `docs/specs/core-loop.md`에 실제 플레이 규칙을 작성합니다.
3. `docs/research/market_report_summary.md`에 시장 리서치 핵심을 요약합니다.
4. Codex 요청 시 `docs/workflows/codex_prompt_templates.md` 템플릿을 사용합니다.

문서 허브: `docs/INDEX.md`
