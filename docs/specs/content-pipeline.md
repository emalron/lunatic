# Content Pipeline Spec

## 1. 목적
신규 캐릭터/무기/스테이지 콘텐츠를 일관된 품질로 빠르게 반영하기 위한 절차.

## 2. 콘텐츠 단위
- 타입: `character | weapon | stage | enemy`
- 최소 산출물:
  - 기획 시트
  - 밸런스 시트
  - QA 체크리스트

## 3. 단계
1. 아이디어 등록
2. 기획 검토
3. 프로토타입 제작
4. 내부 테스트
5. 수정 및 고정
6. 릴리즈 노트 작성

## 4. 완료 정의 (DoD)
- [ ] 핵심 루프와 충돌 없음
- [ ] KPI 영향 가설 작성
- [ ] 로그 이벤트 정의 완료
- [ ] QA 통과
