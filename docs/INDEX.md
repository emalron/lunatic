# Documentation Index

이 문서는 Codex(또는 협업자)가 어떤 문서를 어떤 우선순위로 읽어야 하는지 빠르게 파악하도록 돕는 허브입니다.

## 1) 우선순위 규칙 (항상 상단부터 적용)
1. `docs/game-design/GDD.md` — 게임의 최상위 방향성과 필수 제약
2. `docs/specs/core-loop.md` — 실제 플레이 루프와 시스템 스펙
3. `docs/specs/content-pipeline.md` — 콘텐츠 제작/반영 프로세스
4. `docs/research/market_report_summary.md` — 시장/타겟/벤치마크 핵심
5. `docs/lore/world_setting.md` — 세계관/톤/서사 제약

문서 간 충돌 시:
- 최신 수정일 문서를 우선
- 그래도 모호하면 `질문 리스트`를 먼저 작성하고 구현 보류

## 2) 현재 상태
- 프로젝트 단계: `pre-production`
- 타겟 플랫폼: `mobile`
- 핵심 KPI: `D1 Retention`, `튜토리얼 완료율`, `첫 결제 전환율`
